# Privacy Policy

**Last updated:** November 22, 2026

## Overview
YouTube Scheduler is a personal automation tool used solely by its owner to upload and manage videos on their own YouTube channel and to organize files in their own Google Drive.

## Data Collection
This application does **not** collect, store, transmit, or share any personal data with third parties. No analytics, tracking, or advertising services are used.

## Google API Usage
The application accesses the following Google services exclusively on behalf of the authenticated owner:
- **YouTube Data API v3** — to upload videos, set thumbnails, and update video metadata on the owner's own channel.
- **Google Drive API** — to read and move video files within the owner's own Drive folders.

OAuth tokens are stored privately as encrypted GitHub Actions secrets and are never exposed publicly or shared with anyone.

## Data Sharing
No data is shared with, sold to, or disclosed to any third party. All processing occurs within the owner's private infrastructure.

## Data Retention
No user data is retained by the application. Video files remain in the owner's Google Drive. OAuth credentials can be revoked at any time via https://myaccount.google.com/permissions

## Limited Use Disclosure
This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
